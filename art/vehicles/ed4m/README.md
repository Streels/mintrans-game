# ЭД4М — первый игровой ассет

Внешний облик основан на согласованном зелёно-кремовом концепте и арт-дирекции [темы 18](../../../docs/18_art_direction.md). Геометрия — художественная модель ранней кабины ЭД4М, с укрупнёнными деталями для читаемости в стратегии. Размеры служат согласованию модулей, а не инженерному проектированию.

## Файлы

- `ed4m.blend` — редактируемый мастер Blender 4.5 LTS: три отдельных корневых объекта `ED4M_head`, `ED4M_motor`, `ED4M_trailer`; кузова, двери, окна, тележки, сцепки и оборудование крыши созданы геометрией. Процедурная фактура краски остаётся в мастере.
- `build_ed4m.py` — воспроизводимая сборка модели, GLB и спрайтов; внешние изображения, шрифты и библиотеки не требуются.
- `../../../game/assets/vehicles/ed4m/models/` — три самостоятельных GLB 2.0 со встроенной геометрией и PBR-материалами. Для экономии геометрии мелкие фаски мастера не экспортируются. Голова — 13 689, моторный — 9 572, прицепной — 7 920 треугольников; 11–14 групп материалов на модуль. Постоянные цвета экспортируются без зависимости от процедурных узлов Blender.
- `../../../game/assets/vehicles/ed4m/sprites/` — 24 прозрачных PNG 512×512: по восемь ракурсов каждого вагона. Рельсы и фон в спрайты не входят.
- `../../../game/assets/vehicles/ed4m/ed4m.json` — направления, список файлов, масштаб, точка привязки и шаг сцепления.
- `ed4m-preview.png` — рендер четырёхвагонного состава для визуальной проверки.

## Просмотр в Godot

Из корня репозитория:

```powershell
Godot_v4.7.2-stable_mono_win64.exe --editor --path game --import
Godot_v4.7.2-stable_mono_win64.exe --path game res://scenes/art/ed4m_preview.tscn
```

Либо открыть `game/scenes/art/ed4m_preview.tscn` в редакторе и нажать F6. Кнопки переключают три GLB и движущийся четырёхвагонный состав. ЛКМ справа от панели вращает 3D-вид, колесо меняет его масштаб, пробел останавливает состав. Сцена просмотра не требует сборки C#.

Снимок сцены:

```powershell
Godot_v4.7.2-stable_mono_win64.exe --path game res://scenes/art/ed4m_preview.tscn -- --screenshot=../ed4m-model.png
Godot_v4.7.2-stable_mono_win64.exe --path game res://scenes/art/ed4m_preview.tscn -- --mode=sprites --screenshot=../ed4m-sprites.png
```

## Привязка и направления

Мастер: метры, +Z вверх, кабина смотрит по −Y, нулевая точка в центре вагона на уровне головок рельсов. GLB экспортируется со стандартной осью glTF +Y вверх, кабиной по +Z. Шаг сцепления 22,35 м; длина кузова около 21,5 м. При сборке четырёхвагонного набора используются `head → motor → trailer → head`, задний головной поворачивается на 180°.

Изометрическая камера рендера имеет угол возвышения 30°: оси квадратной сетки дают ромб 2:1. Имена `n/ne/e/se/s/sw/w/nw` относятся к координатам логической сетки, а не к экранным сторонам; в JSON для каждого указан `grid_delta`. Точка `pivot_px` — проекция центра вагона на плоскости рельсов, общая для всех файлов. PNG используют прямой alpha; масштабировать изображение и pivot нужно одинаково.

`Ed4mConsistView.gd` — независимый узел отображения в `game/scripts/Art/`. Он принимает маршрут в координатах сетки, расставляет вагоны по длине пути, разворачивает заднюю кабину и сортирует их по экранной высоте. Размер клетки по умолчанию 128×64 для просмотра; для текущей карты он может быть установлен в 32×16. Цвета, свет и рисунок техники не зависят от состояния грузовой симуляции.

## Границы готовности

Готовы геометрия, отдельные модули, материалы, восемь направлений и сцена проверки в движке. Пантограф поднят, двери закрыты; анимации этих узлов, салон, пассажирская симуляция, электроснабжение и покупка ЭД4М в депо пока не реализованы. В текущем каталоге игры разрешены грузовые модели без электротяги, поэтому этот художественный ассет не добавляет фиктивный пассажирский локомотив в `content/transport/vehicles.json`.

## Пересборка и проверка

```powershell
blender --background --python art/vehicles/ed4m/build_ed4m.py
python art/vehicles/ed4m/validate_ed4m.py
```

Проверка Python требует Pillow и проверяет встроенные GLB, предел числа треугольников, наличие зелёного материала, восемь уникальных направлений, прямой alpha и отсутствие обрезанных спрайтов. Флаг `-- --model-only` у Blender пересобирает GLB и мастер без повторного рендера уже существующих PNG. Параметры камеры и цвета закреплены в скрипте.
