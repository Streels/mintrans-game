# Минтранс — заметки для работы над проектом

- Дизайн и решения: `docs/00_INDEX.md` (оглавление тем) и `docs/DESIGN_v0.0.1.md`. Тема реализуется только после того, как её файл в `docs/` согласован.
- Архитектура и правила модульности: `ARCHITECTURE.md`. Соблюдать их строго: без Godot в `src/`, без циклических ссылок между модулями, типы — данными в `content/`, расширение — новыми классами в реестрах.
- Пользователь получает доклад по каждому пункту оглавления: что сделано, как проверено, что осталось открытым.
- Проверка перед докладом: `dotnet test Mintrans.slnx` и скриншот игры через `--screenshot=`.
- Код и идентификаторы на английском, комментарии и тексты для игрока на русском.
