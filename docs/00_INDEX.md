# Оглавление проектной документации

Это список тем для подробного обсуждения. Зафиксированные основы находятся в [дизайн-документе v0.0.1](DESIGN_v0.0.1.md). Каждую тему будем прорабатывать в отдельном файле из таблицы ниже. Пока тема не обсуждена, указанный файл **не создаётся**; принятые решения затем кратко отражаются в основном дизайн-документе. Темы [01](01_first_prototype.md), [02](02_world_map.md) и [03](03_simulation_time.md) описаны; у тем [04](04_resources_and_chains.md), [05](05_growth_and_generation.md), [06](06_enterprises.md), [07](07_cities.md), [10](10_networks.md), [10а](10a_rail_signals_and_crossings.md), [11](11_vehicles.md), [11а](11a_vehicle_models.md), [12](12_logistics.md), [14](14_era_and_technology.md) и [18](18_art_direction.md) есть черновики.

**Уже решено:** игрок — глава Минтранса; республика, города и предприятия развиваются по собственным правилам; вид изометрический; игрок строит все дороги; первый прототип использует железнодорожный и автомобильный транспорт. В полной игре города и предприятия появляются при генерации карты, во время игры по условиям мира или по дорогому решению игрока. В первом прототипе роста и появления новых объектов нет.

## Порядок работы с темами

1. Выбираем тему и обсуждаем её открытые вопросы.
2. Создаём указанный отдельный файл с принятыми правилами, примерами и оставшимися вопросами.
3. Если решение меняет общую концепцию, обновляем `DESIGN_v0.0.1.md` или следующую версию основного документа.

**Текущая тема:** № 18 — визуальный стиль. Карту отраслей из темы 04 будем дополнять по мере развития проекта.
